# Runtime fixtures

<code>synthetic_invoice.png</code> is an opaque binary fixture generated by
<code>scripts/verify_ingestion.py</code>. It represents the canonical layout
understood by the offline regex extraction path and can be uploaded manually
to <code>POST /v1/ingest</code>.

The verification script intentionally overwrites this file with deterministic
text, rotation, and seeded noise. Do not add a text header to the PNG; its
provenance and role are documented here. Review binary diffs by rerunning the
generator and verification together.
